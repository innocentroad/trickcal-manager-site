# Trickcal Manager

[サイトを開く](https://trickcal.irlab.dev/)

Trickcalの使徒育成・編成・研究を管理し、ダメージやDPSを比較できる非公式ツールです。

## 基本的な使い方

1. 「ステ管理」で使徒を選び、育成・装備・ボード・アサイドなどを設定します。
2. 「編成」で使徒・遺物・スペルを設定します。
3. 「ダメ計算」で自キャラと敵を選び、攻撃や補正を設定して結果を確認します。

DPSは指定した時間のダメージと1秒あたりの平均を比較する機能です。1回の攻撃ダメージとは異なります。暫定対応や未対応の条件は画面の案内を確認してください。

## その他の機能

- 「全体ボード」「一括設定」で複数使徒の設定をまとめて管理できます。
- 研究では段階別の効果、残り研究の必要素材、製作ツリー、所持素材を確認できます。
- 「データ」で使徒・敵・アルバイト素材などを確認できます。
- 「ツール」でビンゴの配置案内やPvPの順位移動を確認できます。
- 編成は共有リンクや画像で共有できます。

## 保存とバックアップ

設定は使用中のブラウザに保存されます。別の端末・ブラウザへは自動同期されません。

重要な設定は「セーブ／ロード」や各画面のエクスポート機能でバックアップしてください。計算設定の保存・読込とエクスポート／インポートも利用できます。

ブラウザのサイトデータ削除やシークレットモードの終了により、保存内容を失う場合があります。旧サイトと新サイトの保存内容も別管理です。

## 注意事項

- 計算結果は比較の目安です。ゲーム内の結果と完全に一致することを保証しません。
- 未対応の効果や暫定的な計算条件があります。各画面の注意・対応状況を確認してください。
- 保存データは自分でバックアップしてください。
- 本サイトは非公式であり、ゲーム運営とは関係ありません。
